# 后续网站设计可复用简报

## 用户偏好

- 需要有辨识度、完成度高、可以适当酷炫的网站；布局与图形要经过整体设计。
- 不接受靠大量同款小卡片、普通图标替换、无意义发光和漂浮来宣称“美化”。
- 图标与主要插图要明确表达功能，适合时可使用有材质和空间感的视觉。
- 这次 GitHub Clear 的原品牌 Logo 需要保留。
- 先提供完整页面的高保真设计图供判断，再实施下一轮页面改版。

## 设计顺序

1. 列出页面主要任务、真实内容与首要行动。
2. 选择一个与产品相符的主视觉方向，确定主次和构图。
3. 设计不等大的模块，说明每块为什么值得占据相应空间。
4. 建立字体、间距、色彩、材质、阴影与图标规范。
5. 制作整屏设计稿，检查信息密度、对齐、文字可读性和视觉焦点。
6. 定义与操作状态对应的动效，再实现布局与交互。
7. 在实际浏览器中检查桌面、窄屏、空状态、长内容及减少动效模式。

## 参考的使用方式

阅读 `reference-study.md`。借鉴《几猫》在构图、材质、光照和完整交互上的方法；根据网站用途重新设计，不套用 FPS 的 HUD、武器、战争题材或全屏场景。

该简报保存在本项目中；跨项目使用时，将此文档提供给对应项目即可复用。
