连接 GitHub / Gitee 账户

进入设置页，在对应平台下填写访问 Token。可以先点击“测试连接”确认账号，再点击“保存 Token”。

  1. 在平台的个人设置中创建访问 Token。
  2. 按照使用需求配置仓库权限。使用 GitHub classic Token 删除仓库时，还需要 delete_repo 权限。
  3. 回到 GitHub Clear 的设置页，选择对应平台并保存。

GitHub 与 Gitee 可以独立使用；只配置一个平台也可以开始管理仓库。

搜索、选择与批量操作

在仓库管理页选择 GitHub、协作仓库或 Gitee。通过名称与描述搜索，或按可见性、更新时间和 Fork 状态筛选。

全选
只选择当前搜索结果。切换平台时，各平台的选择相互独立。
归档
将选中的 GitHub 仓库设为只读，适合保留已经完成的项目。
删除
确认对话框会列出即将删除的仓库，请核对名单后再确认。
退出协作
移除自己对协作仓库的访问权限；退出后可能无法继续访问私有仓库。
部分失败
操作结果会显示成功数量与失败原因，仍存在于列表中的失败项保留选中，方便重试。

编辑与发布个人主页

输入 GitHub 用户名后，可以添加介绍、技能、社交链接和项目组件。右侧支持预览渲染结果和查看 Markdown 源码。

  1. 填写基本信息，按需要选择统计卡片和技能。
  2. 在预览区核对内容，使用复制或下载保存 README。
  3. 点击“部署到 GitHub”，将内容写入当前 Token 对应账号的同名 Profile 仓库。

“恢复默认”会删除该账号自定义的 Profile README；它不是单纯清空本地表单。

设置统计卡片服务

GitHub Stats、Streak 和 Trophies 图片由相应的第三方服务生成。可以在“设置 → 统计服务”填写自己的服务 URL，留空则使用默认值。

如果图片未加载，先检查网络、服务地址与服务自身状态。自部署说明分别放在 Docker 与 Vercel 标签页中。

Git 命令与多账号配置

Git 工具箱提供按类别搜索的命令参考，涵盖本地仓库、远程地址、分支、合并、变基、暂存、回退和标签。每条命令都可以独立复制。

多账号配置包含独立密钥、SSH Host 别名、远程地址切换和按目录设置提交身份。运行前请把示例仓库名、邮箱与路径换成自己的值。

本地运行与部署

在项目目录安装依赖后，可以使用以下命令启动应用。

uv sync
uv run uvicorn main:app --reload --port 8000

在浏览器访问 http://localhost:8000。Token 可以通过设置页、项目的 .env 文件或进程环境变量提供。
